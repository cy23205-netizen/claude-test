# 記述統計（全体像）

写真・動画撮影と体験に関するアンケート（N=116）の、回答分布と T1〜T4 別の基本集計です。

## 実行方法（RStudio）

1. `claude-test.Rproj` を開く
2. 回答の xlsx を `data/survey.xlsx` として置く（`data/` は Git 管理外です。メールアドレスや自由記述を含むため）
3. `analysis/01_descriptive.R` を開いて **Source**
4. 結果は `analysis/output/` に出力されます

使うパッケージは readxl / dplyr / tidyr / stringr / purrr / readr / ggplot2 / scales です。入っていない場合は自動でインストールされます。日本語フォントをきれいに描画するため、`ragg` も入れておくことをおすすめします。

## T1〜T4 の定義

設問 4-1「ここ1ヶ月で一番記憶に残っている体験」の4タイプに、次のように番号を付けています。番号の付け方が違う場合は、スクリプト冒頭の `type_map` を書き換えてください。

| コード | タイプ | n |
|---|---|---|
| T1 | 観客型（ライブ、映画館、スポーツ観戦など） | 28 |
| T2 | 鑑賞回遊型（美術館、博物館、水族館など） | 28 |
| T3 | 演出空間で仲間と過ごす型（テーマパーク、旅行など） | 39 |
| T4 | 機能的な場での活動型（キャンプ、登山、ワークショップなど） | 13 |
| ― | どれも行っていない（4章は未回答） | 8 |

## 処理上の注意

- 自由記述の設問、タイムスタンプ、インタビュー可否、メールアドレスは集計から除いています。
- 選択肢のうち1人しか選んでいないもの（主に「その他」欄への記述）は「その他（自由記述）」にまとめています。1-2（性別）の「その他」1件もここに含まれます。
- 番号のない「次の項目は…」の8項目（撮影に対する態度）は `3_1`〜`3_8` というコードにしています。
- 4-23 は Excel 上で2か所に分かれていたため、列の順に `4-23_1`〜`4-23_9` と番号を振っています（`4-23_1`＝あとで自分で見返すため、`4-23_2`＝記念・思い出 …）。
- 4-11 以降は分岐がある設問なので、設問ごとに回答者数が違います（例：4-15〜4-27 は n=74）。**T4 は人数が少なく**（4-23 では n=7、4-30 では n=6）、T1 も 4-23 では n=8 なので、タイプ間の差は参考程度に見てください。

## 主な結果（全体像）

**回答者**
- 116名。学生が86%、男性56%・女性43%。年齢の中央値は21歳。
- 4-1 の体験タイプは T3（演出空間）が最も多く34%。T1・T2 が各24%、T4 が11%、どれも行っていない人が7%。

**ふだんの撮影**
- 日常の撮影頻度は「週に数回」が42%、「ほぼ毎日」が28%。
- 非日常での撮影目的（2-3）は「記念・思い出」が93%で最多。次いで「あとで見返す」72%、「SNS投稿」55%。

**撮影に対する態度（3_x）**
- 「写真があると思い出しやすい」が平均2.40で突出して高い。
- 「撮る時間があるなら、その場を楽しみたい」（0.47）と「撮っていると集中しにくい」（0.54）は、いずれも平均が中立に近い。

**体験と撮影**
- 体験中に撮影した人は82%。中断の回数（4-12）は「1〜2回」32%、「6回以上」25%。
- 用意された場所・時間以外で撮ったとき、気持ちは「盛り上がっている瞬間」だった人が68%。
- 撮影中の妨げを尋ねた項目（4-24）はおおむね否定寄り。一方、「撮り終えたらすぐ目の前のことに戻れた」は平均1.99、「撮ることも含めて体験だ」は1.58と肯定寄り。
- 「ほかの人の撮影で体験が邪魔された」は平均−1.81で、ほとんどの人が否定。

**T1〜T4 の違い（目立つもの）**
- 4-5「行く前から撮るつもりだった」：T1（観客型）0.18 に対し、T2 1.39、T3 1.10 と高い。
- 4-9_3「慣れて新鮮さが薄れた」：T1 が −1.25 と最も低い。
- 4-8_4「流れが途切れた場面があった」：T4 だけ平均が正（0.31）。ほかのタイプは約 −1.0。
- 4-23 撮影目的：「撮ること自体が楽しい」（T1 −2.75 ／ T3 +0.76）と「SNS投稿」（T1 −0.38 ／ T4 +1.43）でタイプ差が大きい（ただし T1・T4 は n が小さい）。
